# M5-TTS.AXERA

### 50M 参数 · 实时流式 · 六语言 + 方言 · zero-shot 音色克隆

![RTF](https://img.shields.io/badge/RTF-0.53--0.66-brightgreen) ![TTFA](https://img.shields.io/badge/TTFA-0.40%20s-blue) ![TTFT](https://img.shields.io/badge/TTFT-0.06%20s-lightgrey) ![语言](https://img.shields.io/badge/%E8%AF%AD%E8%A8%80-zh%20%2F%20en%20%2F%20de%20%2F%20fr%20%2F%20ja%20%2F%20ko-blueviolet) ![SampleRate](https://img.shields.io/badge/audio-24%20kHz-blue)

| 项目 | 说明 |
|---|---|
| **支持语言** | **中文、英语、德语、法语、日语、韩语**（中/英已上板验证） |
| **推理方式** | C++ / Python，6 个 axmodel 全 NPU2（占 2 核）+ int8 host 表，流式（0.64 s 一包）+ 非流式 |
| **首包时延** | TTFA **0.40 s**、首帧 TTFT 0.06 s（参考音色缓存命中） |
| **实时率** | RTF **0.53–0.66**（C++，3–9 s 句）· 0.84–0.98（Python，缓存命中–首次） |
| **模型体积** | **443 MB**（axmodels 284 MB + int8/fp16 host 表 159 MB） |

> 本分支为 **全 NPU2** 版本：6 个 axmodel 均按 `npu_mode=NPU2` 编译（固定占 2 个 NPU 核）。
> 输出与 `main` 分支逐样本一致（md5 相同），RTF 与 main 基本持平。

- HuggingFace（npu2 分支的预编译模型）: https://huggingface.co/HY-2012/M5-TTS.AXERA/tree/npu2
- 本分支（全 NPU2）: https://github.com/ZY-2012/M5-TTS.AXERA/tree/npu2
- 原始模型: https://huggingface.co/ASLP-lab/M5-TTS-50M-VoiceClone
- 语音 codec: https://huggingface.co/ASLP-lab/M5-TTS-Audio-Tokenizer
- 旧版（fp32，899 MB，RTF 0.48–0.58）：[`v1-fp32` 分支](https://github.com/ZY-2012/M5-TTS.AXERA/tree/v1-fp32)

## 快速开始（AX650 板端）

从 HuggingFace 下载 `models/`、`bin/`、`python/`、`samples/` 到包根目录：

```bash
bash setup.sh

# C++（默认，最快）
bash run_ax650.sh "你好，欢迎使用我们的语音合成模型。" samples/aslp_default_voice.wav \
    "猪携带该疾病，然后通过蚊子传染给人类。" out.wav

# 流式输出
bash run_ax650.sh "你好，欢迎使用我们的语音合成模型。" samples/aslp_default_voice.wav \
    "猪携带该疾病，然后通过蚊子传染给人类。" out.wav --stream

# Python SDK（流式 / 非流式）
bash run_ax650.sh "The voice generated by this model sounds amazing!" samples/aslp_default_voice.wav \
    "猪携带该疾病，然后通过蚊子传染给人类。" en.wav --python --stream

# 调随机种子 / 最长帧数（1 帧 ≈ 80 ms）
bash run_ax650.sh "Hello from AX650!" samples/aslp_default_voice.wav "参考音频转写" en.wav --seed 42 --max-frames 200
```

Python SDK：

```python
import sys; sys.path.insert(0, "python")
from m5_ax import M5AX, write_wav

tts = M5AX("models", "models/assets")
wav = tts.synthesize("你好，欢迎使用我们的语音合成模型。",
                     "samples/aslp_default_voice.wav",
                     "猪携带该疾病，然后通过蚊子传染给人类。")
write_wav("out.wav", wav, tts.sr)
print(tts.last_timing)   # TTFT / TTFA / RTF
```

参考音频 ≤ 4.8 s；单次生成 ≤ 20 s 音频；`prompt-text` 必须是参考音频的准确转写。
同一参考音色在 C++ 下会写入 `cache/ref`（`--no-cache` 关闭），首包时延 0.43 → 0.07 s；Python 写入 `cache/py_ref`，二次运行直接复用。

## 推理速度

| 模式 | 实现 | 音频 | TTFT（首帧） | TTFA（首音频） | 总耗时 | RTF（耗时/音频） | 出包间隔 |
|---|---|---|---|---|---|---|---|
| **流式** | C++ | 3.52 s | 0.06–0.46 s | **0.39–0.76 s** | 1.94–2.33 s | **0.53–0.66** | 0.64 s（首包 0.40 s） |
| **流式** | Python | 3.04 s | 0.17–0.40 s | 0.67–1.05 s | 2.57–2.97 s | 0.85–0.98 | 0.64 s（首包 0.72 s） |
| 非流式 | C++ | 3.52 s | 0.06–0.46 s | — | 2.08–2.35 s | 0.59–0.66 | — |
| 非流式 | Python | 3.04 s | 0.17–0.40 s | — | 2.57–2.97 s | 0.85–0.98 | — |

> 区间为“同一参考音色：缓存命中 – 首次”。C++ 长句（8.72 s，缓存）：TTFA 0.40 s、总耗时 4.67 s、RTF 0.54。

```text

├── bin/m5tts_ax650        # C++ 推理可执行文件

├── python/
│   ├── m5_ax/             # numpy-only SDK

```

## 模型转换

```bash
python model_convert/export_onnx.py        # 6 个子图，逐张量 cosine 校验
python model_convert/fix_reshape.py        # 折叠动态 Reshape shape
python model_convert/export_cpp_assets.py  # tokenizer.bin / codec 表
python model_convert/make_calib.py         # 真实语音校准（含 KV / 卷积状态）
python model_convert/prepare_compile.py --run
```

all-NPU 量化（int8 host 表 + codec RVQ 进图，426 MB 版本）：

```bash
python model_convert/quantize_assets.py                  # int8/fp16 host 表
python model_convert/allnpu/export_allnpu.py             # 新 codec_decoder 图 + 校验
python model_convert/allnpu/prepare_compile.py --run     # 重编 codec_decoder
```

需要准备上游 `ASLP-lab/M5-TTS-50M-VoiceClone` 与 `M5-TTS-Audio-Tokenizer` 权重，
以及 M5 官方推理代码（`M5_SRC` / `M5_LM_BUNDLE` / `M5_CODEC_BUNDLE` 环境变量）。

## C++ 编译

```bash
TOOLCHAIN_ROOT=/path/to/gcc-arm-9.2-2019.12-x86_64-aarch64-none-linux-gnu \
BSP_MSP_DIR=/path/to/ax650n_bsp_sdk/msp/out \
bash cpp/build_ax650.sh
```

板端本地编译：`BSP_MSP_DIR=/soc CXX=g++ CC=gcc STRIP=strip bash cpp/build_ax650.sh`。
