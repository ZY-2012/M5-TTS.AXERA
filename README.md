# M5-TTS.AXERA

**50M · 六语言 + 方言 · zero-shot 音色克隆 · 24 kHz · AX650 全 NPU**

![RTF](https://img.shields.io/badge/RTF-0.48--0.58-brightgreen) ![TTFA](https://img.shields.io/badge/TTFA-0.37%20s-blue) ![TTFT](https://img.shields.io/badge/TTFT-0.07%20s-lightgrey) ![语言](https://img.shields.io/badge/%E8%AF%AD%E8%A8%80-zh%20%2F%20en%20%2F%20de%20%2F%20fr%20%2F%20ja%20%2F%20ko-blueviolet) ![SampleRate](https://img.shields.io/badge/audio-24%20kHz-blue) [![GitHub](https://img.shields.io/badge/GitHub-ZY--2012%2FM5--TTS.AXERA-black)](https://github.com/ZY-2012/M5-TTS.AXERA)

| 项目 | 说明 |
|---|---|
| **支持语言** | 中文、英语、德语、法语、日语、韩语（**中/英已上板验证**）；粤语 `--lang Chinese` + accent 未验证 |
| **推理方式** | C++ / Python，6 个 axmodel 全 NPU，流式（首包 0.40 s，之后 0.64 s 一包）+ 非流式 |
| **首包时延** | 流式 C++ 参考缓存命中 TTFA **0.37 s** / TTFT 0.07 s（首次 0.60 / 0.30 s）；Python TTFA 0.69 s / TTFT 0.08 s |
| **实时率** | RTF **0.48–0.58**（C++，流式 3–8 s 句）· 0.86–1.04（Python） |

## 快速开始（AX650 板端）

从 HuggingFace 下载 `models/`、`bin/`、`python/`、`samples/` 到包根目录：

```bash
bash setup.sh

# C++（默认，最快）
bash run_ax650.sh "你好，欢迎使用我们的语音合成模型。" samples/aslp_default_voice.wav \
    "猪携带该疾病，然后通过蚊子传染给人类。" out.wav

# 流式输出（边生成边写包）
bash run_ax650.sh "你好，欢迎使用我们的语音合成模型。" samples/aslp_default_voice.wav \
    "猪携带该疾病，然后通过蚊子传染给人类。" out.wav --stream

# Python SDK
bash run_ax650.sh "The voice generated by this model sounds amazing!" samples/aslp_default_voice.wav \
    "猪携带该疾病，然后通过蚊子传染给人类。" en.wav --python

# 调随机种子 / 最长帧数（1 帧 ≈ 80 ms）
bash run_ax650.sh "Hello from AX650!" samples/aslp_default_voice.wav "参考音频转写" en.wav --seed 42 --max-frames 200
```

Python SDK：

```python
import sys; sys.path.insert(0, "python")
from m5_ax import M5AX, write_wav

tts = M5AX("models", "models/assets")
wav = tts.synthesize("你好，欢迎使用我们的语音合成模型。",
                     "samples/aslp_default_voice.wav",
                     "猪携带该疾病，然后通过蚊子传染给人类。",
                     lang="Chinese", seed=1234)
write_wav("out.wav", wav, tts.sr)
print(tts.last_timing)   # ttft / ttfa / rtf / 各阶段耗时

# 流式：逐包产出 24 kHz PCM
for pcm in tts.synthesize_stream("...", "samples/aslp_default_voice.wav", "参考转写"):
    ...  # 播放或写入 wav
```

- 参考音频 ≤ 4.8 s（超出截断；内部 24 kHz 单声道重采样 + 去静音）。
- 单次生成上限约 20 s 音频（KV 512 槽 − prompt token 数）。
- `prompt-text` 必须是参考音频的准确转写。
- 首次请求会编码参考音色；同一进程内重复使用同一参考音频会自动命中缓存
  （Python SDK），流式 TTFT 0.41 → 0.08 s、TTFA 1.02 → 0.69 s。

## 推理速度

AX650N（6 GB），Pulsar2 8.0，`U16/S8/U16 + SmoothQuant`。流式：首包后每 **0.64 s** 一包。

| 模式 | 实现 | 音频 | TTFT（首帧） | TTFA（首音频） | 总耗时 | RTF（耗时/音频） | 出包间隔 |
|---|---|---|---|---|---|---|---|
| **流式** | C++（参考缓存） | 3.04 s | 0.07 s | **0.37 s** | 1.52 s | **0.50** | 0.64 s（首包 0.40 s） |
| **流式** | C++（首次） | 3.04 s | 0.30 s | 0.60 s | 1.76 s | 0.58 | 0.64 s（首包 0.40 s） |
| **流式** | Python（参考缓存） | 3.12 s | 0.08 s | 0.69 s | 2.82 s | 0.91 | 0.64 s（首包 0.72 s） |
| **流式** | Python（首次） | 3.12 s | 0.41 s | 1.02 s | 3.23 s | 1.04 | 0.64 s（首包 0.72 s） |
| **流式** | C++ 长句（缓存） | 8.00 s | 0.07 s | 0.39 s | 3.82 s | **0.48** | 0.64 s |
| 非流式 | C++（参考缓存） | 3.04 s | 0.07 s | — | 1.52 s | 0.50 | — |
| 非流式 | C++（首次） | 3.04 s | 0.30 s | — | 1.76 s | 0.58 | — |
| 非流式 | Python（参考缓存） | 3.12 s | 0.08 s | — | 2.82 s | 0.91 | — |
| 非流式 | Python（首次） | 3.12 s | 0.41 s | — | 3.23 s | 1.04 | — |
| 非流式 | C++ 长句（缓存） | 8.00 s | 0.07 s | — | 3.82 s | **0.48** | — |

> TTFT = 首帧 hidden/码本；TTFA = 第一段可播放音频。括号内为同一参考音色的首次/缓存命中。


## 模型转换

```bash
# 0) 环境：torch、transformers 4.57.x、onnx、onnxruntime、soundfile、scipy
#    Pulsar2 8.0（Magnetar）: /root/.cache/magnetar/pulsar2/8.0/bin/pulsar2
# 1) 上游权重放到 origin/（M5-TTS-50M-VoiceClone + M5-TTS-Audio-Tokenizer）
python model_convert/export_onnx.py       # 6 个子图，逐图 cosine 校验（全部 1.0）
python model_convert/fix_reshape.py       # 折叠动态 Reshape shape（Pulsar2 必需）
python model_convert/export_cpp_assets.py # tokenizer.bin / codec 表 / m5_config.h
# 2) 真实语音校准集（12 条语音，含真实 KV / 卷积状态 / mask）
python model_convert/make_calib.py
# 3) 编译
python model_convert/prepare_compile.py --run
```

需要准备上游权重与 M5 官方推理代码；脚本通过 `M5_SRC` / `M5_LM_BUNDLE` /
`M5_CODEC_BUNDLE` 环境变量定位。详见 `model_convert/README.md`。

## C++ 编译

```bash
TOOLCHAIN_ROOT=/path/to/gcc-arm-9.2-2019.12-x86_64-aarch64-none-linux-gnu \
BSP_MSP_DIR=/path/to/ax650n_bsp_sdk/msp/out \
bash cpp/build_ax650.sh
```

在板端本地编译（BSP 头文件与库在 `/soc`）：

```bash
BSP_MSP_DIR=/soc CXX=g++ CC=gcc STRIP=strip bash cpp/build_ax650.sh
```
